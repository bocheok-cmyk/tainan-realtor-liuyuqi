# 台南市國中小學區資料

## 來源

台南市政府教育局官網「臺南市115學年度新生入學期程/國中小學區一覽表」：
https://www.tn.edu.tw/臺南市115學年度新生入學期程-國中小學區一覽表/

- 國小：`source-pdfs/elementary-115.pdf`（原始檔名的下載連結 `download.php?id=17755`）
- 國中：`source-pdfs/middle-115.pdf`（下載連結 `download.php?id=17756`，其餘國中/國小共用同一頁面，另有一份「新生入學期程表」`id=17754` 沒有下載，只是行事曆不是學區資料）
- 下載日期：2026-09-04，對應「115學年度」（PDF上傳日期是2025-12-29，台南市教育局固定在前一年年底公布下學年度學區）

## 抓取方式（明年更新照做）

1. 到上面那個網址頁面，找「附件下載」裡的兩份 PDF（國小、國中學區一覽表，網址每年學年度數字會變，要重新搜尋頁面，不能沿用舊網址）
2. 下載 PDF 後執行：
   ```
   node scripts/update-school-zones.cjs <小學PDF路徑> <小學最大編號> <國中PDF路徑> <國中最大編號> <學年度>
   ```
   例如 `node scripts/update-school-zones.cjs ~/Downloads/小學.pdf 212 ~/Downloads/國中.pdf 65 116`
3. 腳本跑完會印出「可疑記錄」清單，跟原始PDF人工核對這幾筆有沒有解析錯誤，確認沒問題後改 `src/lib/school-zones.ts` 的 import 指向新學年度的檔案

腳本內部：用 `pdf-parse` 套件抽取文字層（**這份PDF是正常可提取文字的**，不像謄本那種特殊編碼，不需要OCR），然後：
- 用「編號」連續遞增偵測法切出每一筆記錄
- 行政區用台南37個行政區的清單精確比對（不要用「是否單字」這種啟發式猜測，會誤判——七/股/區這種行政區名稱拆行時，「區」這個字會被誤判成表頭雜訊濾掉）
- 學校名稱累加到符合「國小/國中/實小/分校/…」結尾為止
- **學區說明文字整段保留原文（`zoneRaw`），不拆解「基本學區 vs 共同學區」的細節** ——這是刻意的設計決定，見下方「資料結構」的說明

**注意**：`pdf-parse` 鎖死在 1.1.1（`package.json` 已固定版本）。2.x 版的文字擷取換行/空格規則不一樣（中文字之間會插入空格、編號有時跟校名黏在同一行），沒有針對2.x重新驗證過這份解析邏輯，升級 `pdf-parse` 前要先確認這個腳本還能正確跑，不要盲目升級。

## 資料結構（`elementary-115.json` / `middle-115.json`）

```json
{
  "no": 5,
  "district": "東區",
  "schoolName": "德高國小",
  "zoneRaw": "東區：和平里，大智里，德高里，崇善里3、7、11-23鄰、仁和里\n東區：東智里(仁德區仁和國小、虎山實小、崇明國小)\n..."
}
```

## 重要：這是「共同學區制」，不是單純一里一校

台南市的學區不是每個里唯一對應一所學校——同一個里（甚至同一個里的某幾鄰）常常可以在兩三所學校之間**自由選填**。`zoneRaw` 裡沒有括號標注的里名是「基本學區」（這間學校唯一負責的範圍），帶括號的里名是「共同學區」（這個里/鄰同時也是括號裡那些學校的學區，家長可以自由選）。

**為什麼沒有把 zoneRaw 拆解成結構化的「基本學區」「共同學區」兩個欄位**：這份 PDF 是兩欄式表格，文字擷取後兩欄內容會混在一起、換行也不規則（cell 內文字自動換行），要完全自動拆解到「這個里的第幾鄰歸哪一校」這麼細，出錯風險很高，而學區資訊是攸關的資料，寧可保留完整原文讓查詢時用關鍵字比對＋讓使用者自己看到原始文字核對，也不要冒錯誤拆解的風險。

## 查詢方式

用 `src/lib/school-zones.ts` 的 `findSchoolsForVillage(villageName, level)`，對 `zoneRaw` 做全文比對，回傳所有提到這個里的學校（含是否帶括號，也就是基本學區還是共同學區）。**這一步只能做到「里」的層級**，還沒有「地址→里」的反查——那需要台南市的村里界線地圖資料，這步還沒做。

## 已知限制

- 只做到「里」層級的查詢，同一個里如果被拆給不同鄰、分屬不同學校，查詢結果會列出所有可能的學校，實際歸屬要看門牌鄰別，畫面上要提醒使用者向教育局或戶籍地確認
- 私立學校、國中小合併、分校這種特殊案例（例如「私立昭明國中(代用國中)」「南大附小」「沙崙高中(國中小部)」）名稱有保留但沒有特別處理
- 每年年底教育局會公布新學年度資料，這批資料需要人工重新跑一次上面的流程更新（不建議做成全自動排程直接覆蓋上線，PDF格式如果哪年改版，解析出錯的代價比人工確認一次的成本高）
